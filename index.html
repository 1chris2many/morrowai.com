TechCrunch

Anthropic opens Claude Duet preview for background work

Anthropic introduced Claude Duet, an Opus 5.5 agent that works on a cloud computer, prepares briefings and dashboards, and requests approval for sensitive actions. It connects with more than 6,000 tools and is available through a waitlist for US Pro and Max subscribers on mobile and the web; Team and Enterprise plans are not yet included. Background checks share the subscriber's existing usage allowance.

Background work saves attention only if the agent knows when to interrupt. Too many approval requests return the supervision burden to the user; too few put consequential actions beyond meaningful oversight. Because Duet's monitoring also consumes the subscriber's allowance, the useful measure is work completed per interruption and per unit of usage—not how long the agent stays busy.

Anthropic — October 22, 2026

Anthropic transfers Agent Skills to the Agentic AI Foundation

Anthropic announced on October 22 that it is donating the Agent Skills standard, its name and logo, GitHub organization and domain to the Linux Foundation's Agentic AI Foundation. The company says more than 70 agent platforms support the format. Maintainers from several companies will steward it, with versioned releases, a proposal process and security guidance on the proposed roadmap.

Procedures learned for one agent are part of the cost of moving work to another. A portable format with shared governance could let teams keep more of that investment when changing providers, making it easier for a rival to win the next task. Execution quality and permissions still differ, so the standard reduces one switching cost without making the agents interchangeable.

Microsoft Research — October 22, 2026

Microsoft adds interactive exploration to AI-generated charts

Microsoft Research introduced Flint-interactive on October 22, a language for specifying chart interactions such as filtering, linked selections and updates across charts and tables. Agents describe the intended interaction while Flint's compiler handles rendering dependencies. The system can be used in chat or embedded in applications.

A static chart forces readers back into a generation loop whenever they want another view. Reusable interactions could let them explore the same data directly, while the compiler absorbs low-level code that an agent would otherwise have to write and debug. That shifts effort toward choosing useful comparisons and validating the data—work that an attractive, responsive chart cannot do for the reader.

TechCrunch

Microsoft reports gains on simulated diagnostic cases

Microsoft reported that its MAI-DxO system reached 83% accuracy on simulated complex medical cases, compared with 36% for individual generalist physicians using reference materials. The Science study evaluates step-by-step questioning and test selection; specialist teams were not the comparison group. Microsoft plans a prospective evaluation with Beth Israel Deaconess Medical Center to examine performance in clinical settings.

A diagnostic application has to add value beyond the increasingly capable models it coordinates. Better test selection, lower workup costs and dependable integration could provide that value even where an extra layer of agents adds little accuracy. The clinical study matters because it can test whether those advantages survive the incomplete information and coordination demands of real care.

TechCrunch

OpenAI opens Decisions API for fast, bounded choices

OpenAI made its Decisions API generally available on October 22, using GPT-6 Luna to classify inputs, score them or select from predefined answers. The release adds native voice integration, prompt caching and support for up to 400 questions per request. Customer Speak reported that one integration reduced the time to its next action from 1.4 seconds to 0.13 seconds in testing.

A decision fast enough to sit between a user's action and an app's response can replace fixed rules without making the product feel slower. That could reduce spending on expensive model calls while opening many more occasions to use AI. The business outcome depends on how often those new decisions run and what mistakes cost; a cheaper choice does not necessarily produce a smaller total bill.

TechCrunch

Uber expands ChatGPT Work to 30,000 employees

Uber is expanding ChatGPT Work from a roughly 1,000-person pilot to its approximately 30,000 employees worldwide. Early non-engineer users built dashboards, analyzed operations data and localized training materials. Uber has not disclosed the rollout's cost and says usage and workflow outcomes will guide its deployment decisions.

The rollout gives non-engineers a route to build analysis tools without waiting for an engineering slot. Whether that frees capacity or creates a second support burden depends on who checks those tools and maintains them after the original builder moves on. Company-wide access gives OpenAI distribution; reliable, repeatable work will determine how much of that access becomes lasting use.
